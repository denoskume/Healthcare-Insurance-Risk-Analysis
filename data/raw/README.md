# Raw data

The project expects these two analytical files in this directory when reproducing the analysis locally:

- `Hospitalisation details.csv`
- `Medical Examinations.csv`

The supplied identity file (`Names.xlsx`) is intentionally excluded from the public repository and from all model features.

The original datasets are not redistributed here until their publication/licensing terms are documented. This repository keeps the complete cleaning, validation, modeling, and evaluation workflow reproducible once the two analytical files are supplied.
