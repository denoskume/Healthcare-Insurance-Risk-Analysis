# Healthcare Insurance Risk Analysis

Machine learning analysis of hospitalisation costs and high-cost patient risk using medical and contextual data.

This repository builds a reproducible applied machine learning workflow for two related tasks: predicting hospitalisation charges and identifying high-cost cases using a threshold learned from the training data only.

The project is designed as a portfolio-grade demonstration of data integration, validation, leakage-safe preprocessing, model comparison, explainability, and error analysis. It is an analytical project, not a clinical diagnosis system.
